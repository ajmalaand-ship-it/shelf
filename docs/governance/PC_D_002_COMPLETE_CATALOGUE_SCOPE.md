# PC-D-002 — Complete Six-Book Catalogue Scope

**Date:** 2026-09-01

**Status:** OWNER APPROVED / GOVERNING FOR CURRENT PC-B WORK

**System:** System C — پېڅوَل

**Stage:** PC-B — Catalogue Completion & Editorial Reconciliation

## Decision

The intended complete Version 1 پېڅوَل catalogue contains all six identified
books:

1. `څپو کې انځورونه`
2. `هېندارې او چینې`
3. `د زړه پر پاڼه مې انځور دی ګلاب`
4. `دا ښار، هاغه غرونه`
5. `دلته ډېر لرې له غرونو`
6. `سيند په پرخه کې`

The first five are Ajmal Aand original-poetry collections. `سيند په پرخه کې`
is a separate translation book: selected poems by original poet پروین پژواک,
translated into Pashto by Ajmal Aand. Collection- and poem-level presentation
must preserve that distinction and must never represent the translated poems
as Ajmal's original-authored poetry. This collection-level classification does
not erase truthful poem-level attribution already present for individual
translations within an original-poetry collection.

This decision supersedes the earlier unresolved product-scope question about
whether `سيند په پرخه کې` belongs in پېڅوَل. It belongs in the intended
catalogue, while its truthful translation classification remains unchanged.

## Trust boundary

Catalogue inclusion does not authorize OCR-derived text, guessing, inferred
poem boundaries, silent correction, AI rewriting, or unsafe partial imports.
A not-yet-imported book remains source-blocked until a trustworthy Unicode
source or owner-approved manual transcription and proofreading process can
preserve its text, structure, metadata, and attribution exactly.

This product decision changes no architecture, security, privacy, entitlement,
authorship, or P5/P6 sequencing. PC remains active and P6 remains not started.
