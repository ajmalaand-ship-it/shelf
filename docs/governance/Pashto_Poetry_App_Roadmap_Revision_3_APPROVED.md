## PC gate

PC completes the intended Version 1 product before release work. It includes protected unpublished owner preview of real content, catalogue/source/editorial resolution, normal user-facing real-content review, owner decisions on remaining Version 1 scope, and closure of actionable completeness defects. Synthetic QA may prove capability and release isolation, but cannot substitute for final real-content acceptance.

The gate passes only when Ajmal explicitly accepts **Product Complete / Ready for Release Preparation**. The first eligible implementation area is **PC-A — Protected Owner Preview / Real-Content Visibility**; it is not started by this governance record.

## Preserved boundaries

- Original voice recordings are ongoing owner-managed editorial content; no fixed minimum count blocks PC.
- P5 real Google Play/RevenueCat configuration and sandbox purchase/restore/paid-audio testing occur in P6 and remain mandatory before final closed testing or production submission.
- QA fixtures remain non-production and cannot authorize paid content.
- No architecture, security, privacy, authorship, isolation or paid-content-protection boundary changes.
